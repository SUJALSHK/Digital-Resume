# Single-Page Digital Resume UI

This is a frontend-only digital resume interface with a compact resume area and a visual AI assistant panel.

## Open Locally

```bash
cd /Users/sujalshakya/Resume
python3 -m http.server 5500
```

Then visit `http://localhost:5500`.

## Current Scope

- Static frontend only
- Placeholder resume content
- Desktop 70/30 resume and assistant layout
- Mobile stacked layout
- Dark and light themes
- Profile/action navigation
- UI-only assistant panel

No backend, database, authentication, API calls, AI connection, or form submission logic has been added.
